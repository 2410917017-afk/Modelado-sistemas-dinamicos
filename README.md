Los proyectos tienen como objetivo realizar la validación entre datos experimentales y datos simulados siguiendo los siguientes pasos:

- Deducción de modelo dinámico matemático.
- Adquisición de datos (sensores pasivos y activos, visión por computadora, etc).
- Transmición de datos con microcontroladores.
- Análisis y procesamiento de señales adquiridas.
- Ajuste de parametros (mínimos cuadrados o ajuste por regresión).
- Simulación del sistema con Python.
- Graficación y validación estadística.

Usando esta metodología podemos analizar la dinámica de sistemas físicos para su posterior uso en estratégias de control.
Obtenemos los modelos físicos usando estratégias de planteamiento cómo leyes de Newton o ecuaciones de Euler-Lagrange.
Después se encuentran funciones de transferencia usando transformada de Lagrange y se analiza según las entradas pertinentes.
