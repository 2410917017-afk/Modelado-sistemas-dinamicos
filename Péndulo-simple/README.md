En este proyecto se construyó un sistema de péndulo simple usando impresión 3D.

Se diseñó y construyó el péndulo usando un potenciómetro para adquirir datos de posición angular.

## Archivos:
/Main.code.py

## Dependencias:
numpy matplotlib signal

Instalar con: pip install ...

## Ejecución:
Soltar la masa desde cierta posición inicial previamente acordada y hardcodeada en el código. Se corre el código y se adquieren datos por medio del microcontrolador. Los datos finales, así como los indicadores de validación se muestran al final del tiempo de muestreo.
